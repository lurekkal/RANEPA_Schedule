# Расписание РАНХиГС — Экономическая безопасность

Статическое веб-приложение для групп ЭБ-5-23-01/02 с автоматическим получением расписания с официальной страницы, отображением последней проверки и истории изменений, календарными режимами и экспортом в Google Calendar через `.ics`.

## Что умеет
- Неделя / месяц / список занятий.
- Фильтр по группе.
- Карточки занятий: дата, время, предмет, тип занятия, преподаватель, аудитория.
- Отдельные поля «последняя проверка» и «последнее обнаруженное изменение».
- История изменений до 50 записей.
- Экспорт в `.ics`, который можно импортировать в Google Calendar.
- Ежедневное обновление через GitHub Actions.

Источник: https://spb.ranepa.ru/raspisanie/ekonomicheskaya-bezopasnost-eb-5-23-01-eb-5-23-02/

## Публикация на GitHub Pages
1. Создай новый публичный репозиторий на GitHub.
2. Загрузи **все содержимое** этой папки в корень репозитория (не саму папку целиком).
3. Открой **Settings → Pages** и в поле Build and deployment выбери **GitHub Actions**.
4. Перейди во вкладку **Actions** и запусти `Update university schedule` через `Run workflow`, чтобы получить первую версию расписания.
5. После первого обновления запусти `Deploy static schedule app` или сделай обычный push. Сайт будет опубликован на GitHub Pages; URL появится в Actions → Deploy static schedule app.

## Автоматическое обновление
Workflow запускается каждый день в 06:17 по московскому времени (03:17 UTC). GitHub Actions может запускать cron с задержкой, поэтому это ежедневная проверка, а не гарантия выполнения ровно в минуту. Workflow также можно запустить вручную в Actions → Update university schedule → Run workflow.

## Важно про даты
Скрипт извлекает даты из таблицы расписания и использует текущий год с переходом на следующий год при переходе с осени на январь/февраль. Если вуз оставит старое расписание на странице или изменит структуру таблицы, нужно проверить результат в `data/schedule.json` и при необходимости обновить парсер. Скрипт не затирает предыдущие данные при ошибке разбора страницы.

## Google Calendar
В приложении нажми **Экспорт .ics**, затем в Google Calendar открой настройки → **Импорт и экспорт** → импортируй файл `.ics`. Экспорт включает предмет, время, преподавателя, аудиторию и группу. Повторный импорт файла может создать дубликаты событий; после обновления расписания импортируй новый файл осторожно.

## Локальный запуск
```bash
python -m pip install -r requirements.txt
python scripts/update_schedule.py
python -m http.server 8000
```
Открой `http://localhost:8000`.

## Ограничение времени изменения
Официальная страница не обязательно публикует точное время, когда сотрудник изменил расписание. Поэтому приложение показывает точное время **обнаружения** отличий при проверке и не выдаёт его за реальное время редактирования на стороне вуза.
